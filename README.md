# ระบบจองห้องประชุมออนไลน์ (Online Meeting Room Booking System)
### วิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์ (Thaluang Cement Thai Technical College)
**Enterprise-Grade Web Application with Next.js 14, Tailwind CSS, TypeScript & Multi-Channel Notifications**

ระบบบริหารจัดการและขออนุญาตใช้ห้องประชุมออนไลน์ ออกแบบตามระเบียบแบบฟอร์มคำขออนุญาตใช้ห้องประชุมทางการของวิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์ พร้อมกระบวนการตรวจรับและอนุมัติ 3 ระดับ และพิมพ์ใบคำขอขนาด A4 ตามต้นฉบับ 100%

## 📋 ตารางเช็กลิสต์ตรวจรับระบบ (System Verification Checklist)

### หมวดที่ 1: ระบบหน้าบ้านและฟอร์มการจอง (Frontend & Booking)
- [x] **ฟอร์มข้อมูลครบถ้วนตามใบคำขอ**: ชื่อ, คำนำหน้า (นาย/นาง/นางสาว), ตำแหน่ง, หน่วยงาน/แผนกวิชา, เบอร์โทรศัพท์, หัวข้อการประชุม, วันที่เริ่มต้น-สิ้นสุด, เวลา, จำนวนผู้เข้าร่วม
- [x] **ตัวเลือกห้องประชุมครบ 6 ห้องหลัก + ระบุอื่นๆ**:
  1. หอประชุมอดิเรกสาร
  2. ห้องประชุมสักทอง
  3. ห้องประชุมหน้าห้องผู้อำนวยการ
  4. ห้องประชุม(กาแฟ)
  5. อาคารโดมเอนกประสงค์
  6. ห้องคอมพิวเตอร์กลาง(ห้องโสต)
  7. อื่นๆ (มีช่องระบุเพิ่มเติม)
- [x] **ตัวเลือกครุภัณฑ์ครบ 6 รายการ + เพิ่มเติม**:
  1. เครื่องฉายภาพ (Projector)
  2. ระบบเสียง
  3. ไมโครโฟน
  4. เครื่องปรับอากาศ
  5. อินเทอร์เน็ต
  6. โต๊ะ/เก้าอี้เพิ่มเติม (ระบุจำนวนตัวได้)
  - ช่องระบุครุภัณฑ์อื่นๆ เพิ่มเติม
- [x] **ปุ่ม Checkbox ยืนยันการดูแลรักษาทรัพย์สิน**: กลไกป้องกันการส่งฟอร์มหากไม่กดติ๊กยืนยันข้อตกลงการดูแลรักษาทรัพย์สินทางราชการ
- [x] **ระบบเช็กเวลาชนกัน (Conflict Detection)**: ตรวจสอบความทับซ้อนของช่วงเวลา `(startA < endB && endA > startB)` ห้ามจองห้องเดียวกันในเวลาที่ซ้อนทับกัน (HTTP 409 Conflict พร้อมแจ้งเตือนหัวข้อและเวลาที่ชน)

### หมวดที่ 2: ระบบแดชบอร์ดและปฏิทิน (Analytics & Calendar)
- [x] **การ์ดสรุปยอดรวม Real-time**:
  - การจองวันนี้ (Today's Bookings)
  - รออนุมัติ (Pending Approvals)
  - อนุมัติแล้ว (Approved Bookings)
  - จำนวนผู้เข้าใช้รวม (Total Attendees)
- [x] **กราฟจัดอันดับเชิงวิเคราะห์**:
  - กราฟจัดอันดับห้องประชุมที่ถูกใช้งานสูงสุด
  - กราฟจัดอันดับแผนกวิชา/หน่วยงานที่ขอใช้บริการสูงสุด (Horizontal Bar Chart)
  - กราฟแนวโน้มคำขอและการอนุมัติรายวัน
- [x] **ปฏิทิน FullCalendar แยกสีตามห้องประชุม**:
  - ตัวกรองเลือกดูรายห้องประชุม พร้อมแถบสัญลักษณ์สี (Color Legend Filter)
  - ตัวกรองค้นหาตามชื่อแผนกวิชา/หน่วยงาน
  - มุมมอง Month / Week / Day
- [x] **ส่วนประกาศประชาสัมพันธ์ (Announcement Banner)**:
  - ประกาศสถานะห้องประชุมหรือข่าวสารจากงานศูนย์ข้อมูลสารสนเทศ/งานศูนย์ดิจิทัลฯ
  - สามารถแก้ไขข้อความประกาศได้จากหน้าตั้งค่าระบบ (Settings)

### หมวดที่ 3: ระบบหลังบ้าน การอนุมัติ และรายงาน (Admin, Notification & Print)
- [x] **ระบบจัดการสถานะ 3 ระดับสำหรับเจ้าหน้าที่และผู้บริหาร**:
  1. **ระดับที่ 1 ตรวจสอบห้อง**: นายวัชรพงศ์ โสภา (เจ้าหน้าที่งานอาคารสถานที่ / Inspector) — ตรวจสอบความพร้อมของห้องและอุปกรณ์
  2. **ระดับที่ 2 รับรองคำขอ**: นายเอกราช เขียวทอง (หัวหน้างานอาคารสถานที่ / Endorser) — พิจารณากลั่นกรองและลงนามรับรอง
  3. **ระดับที่ 3 พิจารณาอนุมัติ**: นายชาตรี เริงชัยภูมิ (รองผู้อำนวยการฝ่ายบริหารทรัพยากร / Approver) — ลงนามอนุมัติขั้นสุดท้าย
- [x] **ระบบแจ้งเตือนแบบ Pop-up และ Webhook**:
  - แจ้งเตือนแบบ Pop-up สวยงามด้วย **SweetAlert2** ทุกขั้นตอน (สำเร็จ, ปฏิเสธ, เวลาชนกัน)
  - ส่งข้อความผ่าน **Webhook แบบเรียลไทม์** (รองรับ Discord, Slack, หรือ Custom Webhook Server) พร้อมระบบทดสอบส่ง Webhook ในหน้า Settings
  - แจ้งเตือนภายในแอปแบบ Real-time ผ่าน Server-Sent Events (SSE)
- [x] **ปุ่มพิมพ์แบบคำขออนุญาตใช้ห้องประชุม ขนาด A4 (@media print)**:
  - จัดวางหน้าตาตรงตามเอกสารต้นฉบับของวิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์ 100%
  - มีช่องกาเครื่องหมายห้องประชุม ครุภัณฑ์ รายละเอียด และช่องลงนาม 4 ช่องตามระเบียบ
  - ซ่อนแถบเมนูและส่วนเกินอัตโนมัติเมื่อสั่งพิมพ์
- [x] **ปุ่ม Export ตารางข้อมูลการจอง**:
  - ส่งออกเป็นไฟล์ **Excel (.xlsx)** พร้อมฟอร์แมตภาษาไทย
  - ส่งออกเป็นไฟล์ **CSV** รองรับ UTF-8 BOM
  - ส่งออกเป็นไฟล์ **PDF** สรุปรายงาน

## 🏢 รายชื่อห้องประชุมหลัก 6 ห้อง (Official Rooms)

1. **หอประชุมอดิเรกสาร** (ความจุ 200 ท่าน, อาคารอดิเรกสาร ชั้น 1)
2. **ห้องประชุมสักทอง** (ความจุ 50 ท่าน, อาคารอำนวยการ ชั้น 2)
3. **ห้องประชุมหน้าห้องผู้อำนวยการ** (ความจุ 15 ท่าน, อาคารอำนวยการ ชั้น 2)
4. **ห้องประชุม(กาแฟ)** (ความจุ 20 ท่าน, อาคารอำนวยการ ชั้น 1)
5. **อาคารโดมเอนกประสงค์** (ความจุ 500 ท่าน, อาคารโดม ชั้น 1)
6. **ห้องคอมพิวเตอร์กลาง(ห้องโสต)** (ความจุ 40 ท่าน, อาคารเทคโนโลยีสารสนเทศ ชั้น 2)
7. **อื่นๆ** (กำหนดรายละเอียดเพิ่มเติมได้ตามต้องการ)

## 🛠️ โครงสร้างเทคโนโลยี (Tech Stack)

- **Framework**: Next.js 14 (App Router, Server & Client Components)
- **Language**: TypeScript
- **Styling**: Tailwind CSS, Lucide React Icons
- **Calendar**: FullCalendar (DayGrid, TimeGrid, Interaction)
- **Charts & Data Viz**: Recharts (BarChart, ResponsiveContainer)
- **Pop-up & Modal Alerts**: SweetAlert2 (Dynamic CDN loader with offline fallback)
- **File Export**: SheetJS (xlsx), JSPDF
- **Real-time SSE**: Server-Sent Events (`/api/events`)
- **Outgoing Webhooks**: Multi-format adapter (Discord, Slack, Teams, Custom)
- **Print Layout**: Pure CSS `@media print` A4 Strict Layout
